## Sobre mí

Mi experiencia se centra en el desarrollo web y la automatización, creando soluciones full stack eficientes y a medida. Me especializo en la construcción de sistemas robustos, la optimización de procesos operativos y el diseño de plataformas estructuradas. Integro tecnologías de desarrollo web con herramientas ofimáticas para generar resultados que impactan directamente en la productividad y el control de metas.
